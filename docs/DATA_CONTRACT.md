# Контракт данных для NLP и ИАС

Версия JSON-контракта: 2.0; извлекатель: rules-0.2.0.

## Идентичность и происхождение

`material_id` идентифицирует карточку производителя по источнику и URL. Он не доказывает тождество разных карточек и не является универсальным SKU. `identifiers` сохраняет доступные manufacturer SKU/MPN/GTIN из JSON-LD.

Существенные признаки исполнения (толщина, размеры, состав, марка, покрытие) должны образовывать отдельное `manufacturer_variant_id` на этапе сопоставления. Для подтверждения розничного предложения требуются оба идентификатора. Запрещено считать одинаковое название достаточным основанием.

`document_id` определяется видом документа, URL и SHA-256 байтов. Изменение содержимого создаёт другой документ; HTTP-кеш хранит время получения отдельно от времени повторного извлечения. Разные URL одинакового файла сохраняют отдельное происхождение; сырые байты дедуплицируются по хешу.

`evidence` содержит `source_url`, `content_sha256`, `locator`, `page`, `quote`, `extractor_version`. XPath относится к сохранённому HTML. Номер страницы PDF начинается с 1. Локально импортированный URL — заявленное происхождение; официальность отдельно не подтверждается.

## Вход NLP

JSONL содержит независимые записи:

| record_type | Значение |
| --- | --- |
| material_metadata | Название, производитель, категория, идентификаторы и идентификатор снимка карточки |
| catalogue_chunk | Текст конкретного раздела карточки |
| document_metadata | Метаданные документа, проблемы качества и состояния всех страниц |
| document_chunk | Текст страницы PDF/HTML с контекстом документа |
| property | Извлечённая строка характеристики, скаляр при однозначном числе |
| applicability_statement | Исходная формулировка применения, монтажа, хранения и т. п. |
| regulatory_reference | Упоминание документа без вывода о соответствии |
| material_document_link | Ссылка производителя на документ для материала |

`start_char:end_char` — срез исходного извлечённого текста страницы/раздела в Python Unicode code points, не байты и не позиции в PDF-файле. Пустые страницы не дают текстовых чанков, но остаются в записи документа с `needs_ocr`. `quote` позволяет проверить основание извлечения.

## Выход будущего NLP-модуля

Рекомендуемые поля нового слоя аннотаций:

```json
{
  "annotation_id": "stable-id",
  "subject_id": "material-or-document-id",
  "predicate": "application_temperature",
  "raw_value": "исходная формулировка",
  "normalized_value": null,
  "unit": null,
  "operator": null,
  "conditions": [],
  "exceptions": [],
  "polarity": "unknown",
  "evidence_ids": [],
  "model_version": "model-and-prompt-version",
  "confidence": null,
  "review_status": "candidate"
}
```

Этот выход пока не реализован: это контракт интеграции. Предсказания следует хранить отдельно от исходных фактов; `confidence` не заменяет экспертный статус. Для каждого значения нужно проверять существование фрагмента-основания в корпусе.

Условия применения должны различать нанесение, твердение, эксплуатацию, хранение и транспортирование. Запрет, разрешение, рекомендация, условное разрешение и отсутствие информации — разные состояния. Из отсутствия запрета разрешение не выводится.

У нормативного требования дополнительно нужны документ/редакция, пункт, субъект, область действия, условия, исключения, связанные пункты и основание применимости. Ссылка «испытано по ГОСТ» не эквивалентна «соответствует всем требованиям ГОСТ». СП может обозначать как строительные своды правил, так и санитарные правила; тип уточняется по карточке документа.

## Розничное наблюдение

Каждая запись фиксирует продавца, SKU, время с timezone, город, магазин, цену и валюту, НДС, наличие, объём упаковки и единицу. Дополнительно: район, адрес, координаты, минимальная партия, остаток и доставка до конкретного назначения. Цена и количество представлены десятичными строками.

Новая цена создаёт наблюдение с новым `observed_at`. Наблюдение не меняет материал производителя. Подтверждённое сопоставление — внешний результат проверки, а не результат сравнения цены.

Сравнение считает `ceil(required_quantity / pack_quantity)` упаковок с учётом минимальной партии. Перевод кг в м³, учёт расхода покрытия, отходов и конструктивных требований относятся к отдельному расчётному слою ИАС. Радиус используется только как географический фильтр магазинов.
